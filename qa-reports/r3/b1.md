## 结论

跨角色审批链在**第 2 节点（PMO）处被身份切换打断**：财务复核通过后，在 `/approvals/APR-1` 切换模拟身份到 PMO 会被整体导航到 `/executive/dashboard`，原单上下文丢失，PMO/集团领导节点无法连续办理，PMO 基线确认与预算版本追加（V1.2 / 3,340.48）本轮因此**未能观察**。财务侧两张关键入口仍缺：`/settlement` 结算列表 404、财务配置三个深链 Tab 全部落在同一 Tab。待办“进入原业务”的疑似路由错误**未复现**（APR-1 正确进入 `/approvals/APR-1`）。

## BLOCK 堵点

- **切换身份到 PMO 丢失审批原单上下文，跨角色链路中断**
  1. 财务登录（刘敏）→ `/workbench/todos`。
  2. 点 APR-1 行“进入原业务”→ `/approvals/APR-1`（正确）。
  3. 填审批意见 → “通过，待基线确认” → 确定；当前节点变为 `2/3 · PMO 评审`。
  4. 顶部角色下拉选 `PMO负责人(李主任)`。
  - 期望：停留 `/approvals/APR-1`，PMO 可直接办理第 2 节点（PMO 默认页面权限含 WK 待办与审批详情）。
  - 实际：URL 变为 `/executive/dashboard`，页面为领导驾驶舱；PMO 视角无“通过”按钮、无当前节点，第 2/3 节点均不可办理，后续 PMO 基线确认与预算 V1.2 追加全部无法完成。
  - 复现率：2/2（两次运行一致）。相关源码线索：`src/components/layout/MainLayout.tsx:91-98` `handleRoleChange` 在 `canStay` 为 false 时 `navigate(ROLE_HOME[val])`，`/approvals/:id` 的角色切换被判为不可停留。

- **`/workbench/executive` 不存在，领导工作台场景无法执行**
  - 直接访问 `/workbench/executive`：路由表无该路径，命中 `src/routes/index.tsx:126` 的 `path="*"` → 404 `StateView`；本轮该页读取 `main` 文本超时，未取到 404 文案（脚本层）。
  - 期望：领导工作台可访问，或明确重定向到 `/executive/dashboard`；实际：404 空页，领导入口只能靠导航菜单/角色首页。
  - 影响：场景 2 的驾驶舱 KPI 核对、`/management-approvals` 列表、executive 待办“进入原业务”、领导审批动作**本轮未观察到**（被测点被 404 前置阻断）。

## BUG 逻辑/功能缺陷

- **`/settlement` 结算列表路由缺失（404 页面未找到）**
  - 财务登录 → 访问 `/settlement`：实际 URL 仍 `/settlement`，`main` 文案 `404 页面未找到 | 抱歉，您访问的页面不存在或已被移除 | 返回首页`。
  - 期望：财务有结算申请列表（含 SET/SREQ、锁定状态、待核算筛选）；实际：只能用 `/projects/:id/settlement` 逐项目直达，无法横向核对。

- **财务配置三个深链 Tab 全部落在“四算科目与映射”**
  - 分别访问 `/settings/cost-mapping`、`/settings/cost-baseline`、`/settings/alerts`；三次激活 Tab 均为 `四算科目与映射`（二级 `科目树与使用情况`），页面标题同为“财务配置”。
  - 期望：深链分别激活“成本基准配置”“预警规则配置”；实际：路由参数未驱动 Tab（`src/routes/modules/configuration-finance.tsx:5` 三条路由复用同一 `FinanceConfigurationPage`，未见 path→tab 绑定）。
  - 影响：外部/待办/文档给出的深链一律落到首个 Tab，用户需再手动切换。

- **财务待办缺 SREQ-2“财务核算”事项，与原单状态不一致**
  - 财务登录 → `/workbench/todos`：`待办（21）/ 已办（31）`，首屏 11 行；全表无任何 `SREQ-` 编号（`命中=无`）。
  - 但 `/projects/P-023/settlement` 页面明示“建设期成本已冻结（**SREQ-2**）：结算核算及评审中”，说明状态里存在 SREQ-2 且应待财务核算。
  - 期望：SREQ-2 作为“我审批的 财务核算”出现在财务待办并可“进入原业务”；实际：待办列表不覆盖该事项，财务无法从待办入口进入核算。

## FLOW 流程问题

- **P-023 结算页不展示 SET-0008 记录，锁定只读无法核对**

  - 期望：待结算项目下列出 SET-0008 已锁定记录并可点开详情核对四算/锁定只读；实际：列表不渲染结算申请记录 → 详情只读断言无法执行。

- **审批链第 3 节点与 PMO 基线确认本轮未验证（被身份切换 BLOCK 阻断）**
  - 结果旁证：`/projects/P-001/budget` 生效基线仍为 `V1.1`、无 `V1.2`、无 `3,340.48`；这与“审批未走完”一致，属未验证而非缺陷。
