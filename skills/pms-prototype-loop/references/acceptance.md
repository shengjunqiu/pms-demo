# 页面与最终验收

本文件用于开发时选取需要的测试；不要为可逆小改写大量镜像测试。业务公式、状态门和权限对结果影响大，使用领域测试；页面交互与视觉使用实际浏览器。

## 页面类型

| 类型 | 必须具有的可观察能力 |
|---|---|
| 台账 | 查询/重置/更多筛选、排序/分页、列设置/查询方案、状态、至少一个下钻、行操作；导出可明确模拟 |
| 详情 | 项目/业务对象摘要、状态/角色、Tabs、原单据与版本、时间线；金额/数量能进入相关明细 |
| 编制表单 | 分组、必填与跨字段校验、自动带入、实时汇总、草稿/取消/返回/提交确认、规则命中提示 |
| 评审审批 | 材料与版本、命中规则、流程节点/人员、历史意见、通过/整改/否决语义；动作更新原对象 |
| 分析 | 数量与金额并列、指标口径/更新时间、图表问题明确、筛选贯穿、指标→清单→项目→明细 |
| 配置 | 有真实感规则数据、字段与作用范围、启停/版本/生效日、关联业务使用该配置，标注演示规则 |

上传在浏览器内显示文件名/版本/校验，导入可模拟模板预览与错误结果；不要求真正Excel/PDF导出，不假称已连接服务器。关键提交、审批、变更、风险关闭等不能只弹成功提示而不修改共享演示状态。

## 视觉标准

- 专业中文ToB：清晰层次、高信息密度、表格/详情合理分组；避免大量渐变、卡片墙、夸张动画、大面积装饰留白。
- AntD 5统一tokens；左导航220–240px，Header56–64px；1440×900设计基准，1280最低宽度。复杂表格允许局部横滚，不让整个页面溢出。
- 健康/完成绿、进行蓝、关注橙黄、预警橙、高风险/超期/驳回红、草稿灰；颜色之外同时有状态文字及异常原因。
- 小金额`¥ 128,500.00`，大金额万/亿且Tooltip显示完整值；偏差带正负；比率一位小数；日期`2026-09-09`，时间`2026-09-09 18:30`。
- 每页有标题、Breadcrumb、合理主次操作；分析类有数据更新时间和口径。无Lorem ipsum、Project A、占位图、未完成功能提示。
- 截图检查文字溢出、筛选拥挤、按钮对齐、表格固定列、Drawer/Modal遮挡、图例/坐标可读性、金额列和单位。查看页面初态及关键展开态。
- GL-01额外演示：正常、部分源延迟、无数据、无权限、计算中、口径变更。统一状态控制入口可放开发演示区，不在普通业务流程暴露实现细节。

## 浏览器检查

有可用浏览器工具就实际访问，优先现有工程测试能力；使用Playwright时加载可用的playwright技能。没有自动化工具可使用实际浏览器工具验证并记录；不能把静态阅读称为浏览器验证。

每个新增页面：导航/对象进入→核对页面独有字段→关键动作→观察业务数据及关联页变化→返回→检查控制台→两种宽度截图并查看。动态路由使用有效ID；检查unknown-ID空态与无权限态。健康度筛选下钻不能换成其他项目集合。

适当给关键控件稳定的语义标签或`data-testid`；测试断言业务内容与状态变化，避免匹配任意文案就通过。共用组件/selector修改需要回归受影响路径。

## 五条业务链路

| 报告键 | 路线 | 至少一个分支/不变量 |
|---|---|---|
| estimate | GS-01→03→04→05→06→07→08→10/11 | 评审整改新版本；投入成本后续继承不双计 |
| budget | YS-01→02→03→04→05→06→07→08→09→10→11→12→15 | 超概算可存草稿、提交进高级审批；未签走YS-13/14且启动被阻断 |
| accounting | HS-01→02→03/04→07/08→05/06→09→10/11/12→13→14/15→17/16 | 问题与BUG关闭人区别；变更新基线；缺必交物不能切阶段 |
| settlement | JS-01→02→03→04→05/06→07→08→09→10→11/12或13 | 客户整改保留轮次；结算锁建设成本；运维不污染结算 |
| leadership | GL-01→05→HS-01→HS-13或08→GL-02→GL-06→原审批 | 组织/时间/健康筛选保持；数量和金额与明细一致；不重复审批 |

链路不要求全部复用同一个静态项目：需要新建流程用新的临时对象；成本用P-001，严重异常用P-003，未签用P-004，验收整改用P-006，运维用P-007，结算复盘用P-008。不同阶段切换必须遵守状态门，不为走演示而改写同一项目历史。

两条角色演示：

- `manager-demo`：项目经理身份WK-01→在建项目→WBS/里程碑→动态核算→问题风险→项目变更→阶段门→客户验收→结算/四算；必要时切换到已准备好相应阶段的演示项目并明确说明。
- `executive-demo`：领导身份GL-01→高风险项目→异常原因→四算偏差→待决策→原事项；管理视角默认只读，决策动作遵守原业务权限。

6. 全部功能ID映射已核对；集成/生产非功能范围明确。字段权限为前端模拟，不声称安全隔离已落地。

路由说明至少列编号、路由、入口、参数对象、可用演示ID；Mock说明至少列seed/asOf、数量、故事、实体关系、单位/公式、演示规则、状态如何重置、未接真实系统的范围。README中的命令须实际运行验证。
