## 数据组织

使用统一TS类型、固定seed工厂、固定`asOf`演示日、实体仓库、纯selector和模拟service。可模拟150–500ms延迟。日期由固定基准派生，不在render中用随机数/实时日期生成经营指标。

```text
组织→用户/客户；商机→方案/评审/概算版本/提前投入
商机→立项→项目→客户合同/团队/基线/预算/WBS/里程碑
项目→工时/采购/外包/费用→成本流水
项目→需求/BUG/问题/风险/变更/交付物/阶段记录
项目→验收轮次→结算版本→归档→运维周期
审批/预警/待决策/审计→原业务对象ID→项目或商机
```

`:id`按页面实体类型绑定；问题详情不能塞入P-001，运维详情使用运维周期ID。验收使用真实存在的fixture ID。

正式项目≥60、未签子集≥10、运维子集≥12；后两者可包含在60中。商机≥36不是上限；单商机转单项目时生成足够来源商机，不用孤立项目凑数。

## 计算规则

建议金额用整数分，统一显示为元/万元/亿元；已有工程用元则保持单一单位并明确舍入策略。展示舍入数不得参与汇总。

```text
概算 E = 指定冻结概算版本的叶子科目合计
预算 B = 当前生效预算版本的叶子科目合计
实际 A = 已确认人力+采购+外包+费用流水（去重）
未发生承诺 C = 承诺总额 − 已计入实际部分
剩余预测 R = 尚未包含在A/C中的未来成本
滚动 F = A + C + R
预测成本偏差 = F − B
滚动偏差率 = (F − B) / B
执行率 = A / B
剩余预算 = B − A
预测毛利 = 当前收入 − F
预测毛利率 = 预测毛利 / 当前收入
结算毛利 = 最终收入 − 冻结结算实际成本
```

未明确财务口径记录为演示假设：

- 建设成本/期间费用可作父级，不再与采购/外包/差旅子科目重复相加；四算用统一叶子科目及映射版本。
- 工时/采购/费用是成本流水的来源，不是第二份成本；前期成本继承保留sourceId，商机/项目不双计。
- C是未发生余额，不是整张合同额。承诺兑现时A增加、C等额减少，F不凭空增加。
- 零预算/零收入比率返回null，显示“—”及原因；未知/未结算不伪装为0。结算比较仅含已结算项目；组合四算注明共同样本范围。
- 组合毛利率=汇总毛利/汇总收入；回款完成率=汇总实收/对应范围计划应收，标明是否截至演示日。不得平均项目比率。
- 预计收入、立项金额、签约额、应收、实收分字段；P-004不计已签合同额。多合同按ID去重。
- 历史趋势取日期快照；结算对比取执行期最后有效滚动快照，不混入运维成本。

P-001基准（万元）：偏差138.50；预测毛利2,552.10；偏差率约4.86%；预测毛利率约46.08%。先验基础数/科目合计，再验格式化。

## 健康、筛选与角色

统一 `evaluateHealth(project, rules, asOf)` 返回等级、规则ID、严重度、关键值、原因和业务目标ID。取最严重命中，展示前1–3项。30天、15%、14天等仅是配置中的演示值。

selector先限定角色范围，再应用组织/区域/时间/类型/健康筛选，最后聚合。KPI与下钻用相同筛选对象；组织子树项目去重。切换角色重算并清理无权限缓存/选择。

至少6种身份：集团领导、PMO、项目经理、市场/主办、财务、方案/技术。模拟菜单、首页、范围、按钮、只读及敏感字段权限。

## `test:domain` 的可观察不变量

使用项目实际测试工具，不指定私有测试协议。

1. 31类数据最低数量、ID唯一/引用存在、seed/asOf可重现、8个故事及关联记录符合约束。
2. 成本科目与总额相等；承诺转实际及前期继承不重复；零分母、亏损、无结算不产生NaN/Infinity。
3. 聚合与同筛选明细求和相等；组织不重复计数；毛利率为金额加权；未签金额口径正确。
4. 冻结版本不可原地编辑；批准变更新增版本、驳回保持旧版；审批引用不跳动。
5. 错误角色不能最终关问题/BUG；交付物阻断阶段；未签超限不能绕过；结算锁定建设成本。
6. 模拟操作修改原对象，工作台、详情、核算、异常、决策随之更新。

不要通过降低数量、删失败断言、硬编码计算结果使检查通过。
