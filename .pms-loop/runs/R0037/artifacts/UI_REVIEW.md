# 第一轮 UI 优化记录

范围：项目经理工作台（WK-01）、经营驾驶舱（GL-01）、项目详情（HS-01），以及公共标题、导航和指标组件。

## 已实施

| 页面/组件 | 原问题 | 调整 |
|---|---|---|
| 工作台 | 待办位于项目表格之后，十二个快捷按钮挤在同一行 | 待办与临期里程碑前置；采购、外包、费用常显，其余九项由更多发起访问 |
| 驾驶舱 | 筛选、说明、统计占据首屏，异常与决策靠后 | 默认组织/健康度筛选，其他条件可展开；指标后紧接异常与待决策 |
| 项目详情 | 泛化标题、十五个页签溢出、卡片嵌套 | 以项目名称为标题；五个业务分组承载全部旧页签；概要指标使用无边框样式 |
| 标题与导航 | 重复显示开发编号与页面类型 | 显示业务名称，导航自动展开当前组并高亮动态路由入口 |
| 指标 | 高度不齐，不可点击指标也有悬停交互 | 独立指标统一最小高度；仅可点击指标具有悬停与键盘焦点，支持Enter/空格 |
| 健康状态 | 高风险文字可能落入绿色默认样式 | 明确匹配高风险并显示红色；保留文字标签 |

## 保持的业务语义

- 使用原有统一业务状态与计算，无新增一份项目、预算或审批事实。
- 快捷动作仍在原业务页面办理，并携带选中的项目。
- 项目详情保留原有 tab 参数、类型筛选和所有十五个内容入口；切换项目、返回均保留上下文。
- 驾驶舱仍保留完整筛选、常用视图、口径、六种演示状态、原审批及金额下钻。
- 偏差显示正负；无预警不再被描述成全部健康；在管项目卡不再固定宣称运行正常。
