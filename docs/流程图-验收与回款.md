```mermaid
    ACCEPT[开始验收] --> S1[内部初验 第1轮]

    S1 --> R1{验收结果}
    R1 -->|通过 ✅| S2[供应商验收 第1轮]
    R1 -->|整改 🔧| FIX[整改中]
    FIX -->|重新提交| S1

    S2 --> R2{验收结果}
    R2 -->|通过 ✅| S3[客户终验 第1轮]
    R2 -->|整改 🔧| FIX

    S3 --> R3{验收结果}
    R3 -->|通过 ✅| DONE[✅ 验收完成]
    R3 -->|整改 🔧| FIX

    DONE --> SETTLE_TRIGGER[触发结算流程]
  end

  subgraph RECEIPT["回款流程"]
    direction TB
    RECEIPT_START[回款计划] --> P1[合同首付款]
    P1 -->|已收 2,492.24万| P1_DONE[首付款核销]
    RECEIPT_START --> P2[验收结算款]
    P2 -->|应收 3,046.07万| P2_WAIT[等待验收完成]
    P2_WAIT -->|验收通过后| P2_DONE[结算款核销]
  end

  subgraph ROLES["角色职责"]
    R1["👤 项目经理（张建国）<br/>组织验收、确认验收结果"]
    R2["👤 财务专员（刘敏）<br/>回款核销、到账确认"]
  end

  R1 -.-> S1
  R1 -.-> S2
  R1 -.-> S3
  R2 -.-> P1_DONE
  R2 -.-> P2_DONE

  %% 问题标注
  DONE -.->|"⚠️ 验收→回款<br/>缺少自动联动"| ISSUE1
  FIX -.->|"⚠️ 整改→重新验收<br/>路径不清晰"| ISSUE2
```

## 说明

- **验收三阶段：** 内部初验 → 供应商验收 → 客户终验（每阶段支持多轮次）
- **整改闭环：** 任一阶段不通过进入整改，整改完成后重新提交该阶段验收
- **回款计划：** 合同首付款（已收 2,492.24万）+ 验收结算款（应收 3,046.07万）
- **问题：** 验收通过后未自动触发回款计划更新；整改→重新验收的 UI 路径不直观
