## 二、发现的问题

### ⚠️ 问题 1：立项通过后无导航到项目页

**位置**: `src/pages/initiation/InitiationDecisionPage.tsx`

**现象**: 当 `decide-initiation` 结果为"通过"时，代码只执行 `message.success("决策已记录")`，没有自动导航到新创建的项目页面。用户需要手动回到评审工作台或商机详情页找到项目。

**影响**: 用户不知道项目已创建成功，需要额外操作才能进入项目。

**建议修复**: 在 `message.success` 后添加导航：
```typescript
if (result === '通过') {
  const project = useBusinessStore.getState().data.projects.find(p => p.opportunityId === app.input.opportunityId);
  if (project) navigate(`/projects/${project.id}`);
}
```
