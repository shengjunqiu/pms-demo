## 三、死链路（5 条）

### 🔴 3.1 `maintenanceCosts` — 完全死字段

| 维度 | 说明 |
|------|------|
| **位置** | `BusinessState.maintenanceCosts: CostItem[]` |
| **入口** | `confirm-cost` action 的 `maintenance=true` 分支 |
| **问题** | 该分支第一行就是 `throw new Error('运维费用请通过周期原单填报...')`，**永远无法写入** |
| **出口** | 没有任何页面读取此字段 |
| **结论** | 完全死代码，可移除 |
