# 项目管理平台详细功能清单

> **文档版本：** V1.1  
> **编制日期：** 2026-09-09  
> **对应 PRD：**《项目管理平台 PRD V1.0——基于项目四算四阶段流程》  
> **业务主线：** 概算 → 预算 → 核算 → 结算  
> **使用说明：** 本清单用于需求评审、原型拆页、研发任务拆分和测试用例设计。功能描述按“页面/功能点 + 操作能力 + 业务规则 + 结果”展开；流程图及 PRD 未明确的金额、毛利率、时限、风险阈值等，不在本清单中写死，统一由规则配置中心维护。

---

# 1. 功能清单说明

## 1.1 功能分级

- **一级模块**：面向业务阶段或平台级能力的产品模块。
- **二级模块**：一级模块下相对独立的业务域。
- **三级功能**：可直接落实到页面、按钮、表单、规则、查询或后台任务的功能点。

## 1.2 功能项字段说明

| 字段 | 说明 |
|---|---|
| 功能编号 | 用于需求、原型、研发、测试之间建立追踪关系 |
| 一级模块 | 对应产品一级导航或业务域 |
| 二级模块 | 一级模块下的业务分组 |
| 三级功能 | 可落地的具体功能点 |
| 功能说明 | 说明用户可以做什么、系统需要做什么 |
| 主要角色 | 该功能的主用角色，不代表唯一可见角色 |
| 关键业务规则 | 关键校验、状态、流转、数据约束 |
| 主要输出 | 产生的数据、状态、单据、版本或后续流程输入 |

# 12. 下一步原型拆解建议

为了避免一次性把全部功能点铺到原型里，建议原型按业务主线分四批推进：

1. **第一批：概算 + 立项主链路**  
   商机台账 → 商机评估 → 方案/成本 → 专家评审 → 概算 → 立项申请 → 立项决策。

2. **第二批：预算 + 项目基线**  
   项目团队 → WBS/里程碑 → 资源计划 → 项目预算 → 预算审批 → 基线 → 未签管控。

3. **第三批：项目执行 + 动态核算**  
   项目工作台 → 进度 → 日报 → 风险问题 → 需求BUG → 工时 → 采购/外包/费用 → 动态核算 → 变更 → 阶段切换。

4. **第四批：验收 + 结算 + 分析**  
   内部验收 → 供应商验收 → 客户验收 → 项目结算 → 四算分析 → 后评价 → 运维/关闭 → 项目经营驾驶舱。

在原型阶段，每个功能页面建议继续补充以下四项：

- 页面信息架构；
- 字段级清单；
- 按钮与交互规则；
- 状态流转及异常提示。
