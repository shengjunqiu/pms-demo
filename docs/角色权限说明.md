## 2. 权限维度说明

| 维度（代码字段） | 中文 | 说明 |
|:---|:---|:---|
| `pages` | 页面白名单 | 每角色拥有可见页面集合，管理员端可进一步收紧 |
| `actions` | 业务动作白名单 | 每角色拥有可执行业务动作集合，超过 100 种动作标识 |
| `dataScope` | 数据范围 | 可选值：`self`（本人参与）/ `department`（本部门）/ `department-tree`（部门及下级）/ `organizations`（指定组织及下级）/ `all`（全集团） |
| `projectRelationRequired` | 项目关系要求 | `true` = 必须存在有效参与关系才可访问项目数据；`false` = 按数据范围规则 |
| `fields` | 敏感字段可见性 | 控制以下四个敏感字段的可见性 |
| `editableFields` | 敏感字段编辑权限 | 在上述四个字段中可选可编辑子集 |

### 2.1 敏感字段定义

| 敏感字段（`SensitiveField`） | 中文标签 | 说明 |
|:---|:---|:---|
| `labor-rate` | 人员成本单价 | 小时单价、日单价、费率等 |
| `margin` | 毛利与收益 | 毛利、利润率、收益相关数据 |
| `evaluation` | 经营评价与绩效 | 项目后评价评分、绩效数据 |
| `contact` | 联系方式 | 手机号、邮箱等客户/人员联系方式 |

> **注意**：`margin`（毛利与收益）为自动计算只读值，不能直接编辑。

### 2.2 条件性动作

以下业务动作除角色白名单检查外，还需额外的动态条件才能执行：

| 动作标识 | 中文 | 额外条件 |
|:---|:---|:---|
| `decide-initiation` | 立项决策 | 当前审批节点包含该角色，且该角色尚未在此节点审批过 |
| `review-early-investment` | 提前投入审批 | 请求状态为待审批且在用户管辖范围 |
| `reply-planning` | 计划整改回复 | 用户是被指派的整改责任人，或项目经理可代回复 |
| `score-post-evaluation` | 后评价评分 | 后评价状态为"编制中"且用户为指定评价人或 PMO/项目经理 |
| `accept-operation-handover` | 接受运维交接 | 用户是交接记录的接收人且状态为"待接收" |
| `submit-operation-cost` | 提交运维成本 | 用户在运维周期团队中或角色为 PMO |
| `record-operation-event` | 记录运维事件 | 用户在运维周期团队中或角色为 PMO |
| `resolve-operation-event` | 解决运维事件 | 用户在运维周期团队中或角色为 PMO，事件未解决 |

### 2.3 数据范围说明

| `dataScope` 值 | 中文 | 含义 |
|:---|:---|:---|
| `self` | 本人参与 | 仅能看到本人参与的项目（主PM、团队成员、待接受任命、商机负责人、运维成员）|
| `department` | 本部门 | 仅能看到本部门的项目 |
| `department-tree` | 本部门及下级 | 能看到本部门及其所有下级部门的项目 |
| `organizations` | 指定组织及下级 | 仅能看到指定组织（及下级）的项目 |
| `all` | 全集团 | 全集团所有项目 |
