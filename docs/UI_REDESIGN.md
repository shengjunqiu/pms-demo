用户授权：上一轮3页完成后，持续改造其余全部69页。覆盖72页及关联审批入口，不扩大为后端或部署。

本清单只记录范围安排，不替代 `.pms-loop/state.json` 的正式验收状态。每包至多5页，重新验收使用当前源码的工程检查、真实交互和双宽截图；最终执行全量回归。尚未开始UI改造的页面保留原业务验收历史。

## 设计方向

- 列表：常用筛选优先，次要条件可展开；保留筛选上下文、列设置、金额口径与原单据操作。
- 表单：按业务顺序分区，主提交动作与次级动作分层；保留所有字段与校验。
- 详情：优先对象、状态、关键金额和主动作；版本、来源、历史及说明分区。
- 分析：指标、差额与异常优先；图形使用现有统一计算。
- 页面逐批迁移灰工作区与白业务分区；检查1280/1440宽度，表格独立水平滚动。
