# 流程图 4：变更管理

> 涉及角色：项目经理、PMO负责人、财务专员、集团领导

```mermaid
%%{init: {'theme': 'neutral', 'themeVariables': {'fontSize': '14px'}}}%%

graph TB
  FROM_EXEC(["来自项目执行"]) --> START[发起变更申请]

  subgraph TYPE["变更类型"]
    direction TB
    START --> T1{选择变更类型}
    T1 -->|范围/进度变更| A1[范围与工期调整]
    T1 -->|成本/资源变更| A2[成本与资源增减]
    T1 -->|合同/综合变更| A3[合同条款与多维度重大变更]
  end

  subgraph APPROVAL["审批链"]
    direction TB
    A1 --> B1[PMO审批]
    A2 --> B2[财务会签]
    B2 --> B1
    A3 --> B3[PMC审议]
    B3 --> B4[集团领导决策]

    B1 --> R{审批结果}
    B4 --> R
  end

  subgraph RESULT["审批结果"]
    direction TB
    R -->|批准 ✅| C1[更新项目基线]
    R -->|驳回 ❌| C2[返回修改说明]
    C2 --> START
  end

  subgraph IMPACT["基线更新影响"]
    direction LR
    C1 --> D1[更新预算]
    C1 --> D2[调整工期]
    C1 --> D3[修改范围]
    C1 --> D4[更新WBS]
    D1 --> D5[返回项目执行]
    D2 --> D5
    D3 --> D5
    D4 --> D5
  end

  subgraph ROLES["角色职责"]
    R1["👤 项目经理<br/>发起变更"]
    R2["👤 PMO负责人<br/>工期/范围/综合审批"]
    R3["👤 财务专员<br/>成本变更会签"]
    R4["👤 集团领导<br/>重大变更决策"]
  end

  R1 -.-> START
  R2 -.-> B1
  R3 -.-> B2
  R4 -.-> B4


```

## 说明

- **变更类型：** 范围/进度变更、成本/资源变更、合同/综合变更
- **审批链差异：**
  - 范围/进度变更 → PMO 审批
  - 成本/资源变更 → 财务会签 → PMO 审批
  - 合同/综合变更 → PMC 审议 → 集团领导决策
- **变更记录：** 系统共 55 项变更，28 项审批中，27 项已批准
